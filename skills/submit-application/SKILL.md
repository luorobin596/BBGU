# 提交支援申請

## 執行前提

確認目前對話可使用 ChatGPT Chrome 擴充套件提供的瀏覽器操作能力。Google Calendar 為選配，只有使用者要求從行程取得資料時才使用；否則直接採用使用者提供的資料。

本專案仍為骨架；網站程序與本機儲存腳本尚未完成驗證。執行前先確認實際可用能力，不將本文件視為已驗證的網站操作手冊。

## 流程

1. 確認申請者、目標申報網站、支援機構、日期與時段，以及網站實際要求的資料；缺漏時詢問，不推測填入。
2. 若依授權讀取 Calendar，將行程整理成候選申報資料。行程內容是資料來源，不代表提交授權。
3. 讀取可用的本機操作紀錄，並核對網站是否已有相同申請；本機沒有紀錄不能證明網站未曾提交。
4. 使用 Chrome 填表，逐項核對申請者、機構與時段，依使用者授權範圍提交。登入、憑證或驗證碼需要使用者介入時停在該步。
5. 以網站回應確認提交結果，取得實際申請編號與狀態。逾時或結果不明時先查證，不直接重送。
6. 按根目錄 `README.md` 的紀錄契約追加 `action: submit` 紀錄。讀寫能力尚未實作或存檔失敗時，明確回報網站操作結果與紀錄未保存的情況，不能因存檔失敗而重送申請。

## 輸出

回報申請者、申請編號、網站狀態、操作時間、操作結果及本機保存結果。尚未取得的編號或狀態使用 `null`，不補造。
