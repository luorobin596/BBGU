# 撤銷支援申請

## 執行前提

需要目前對話可用的 ChatGPT Chrome 操作能力，且使用者已授權撤銷目標申請。Google Calendar 不是撤銷必要工具。

本專案仍為骨架；網站程序與本機儲存腳本尚未完成驗證，執行前先確認實際可用能力。

## 流程

1. 確認申請者、目標網站及申請編號；可依根目錄 `README.md` 的紀錄契約讀取本機紀錄，協助定位。
2. 透過 Chrome 讀取網站詳情，核對申請者、編號、機構、時段與目前狀態。無法唯一辨識目標時先請使用者指定。
3. 依網站提供的功能及使用者授權撤銷；既有授權已明確涵蓋目標時不重複要求確認。網站不允許撤銷時回報原因。
4. 讀取撤銷結果並再次查詢確認。逾時或結果不明時先查證，不盲目重試。
5. 追加 `action: withdraw` 的操作紀錄，保留網站實際狀態與操作結果，不刪除先前歷程。存檔失敗不代表網站撤銷失敗，須分別回報。

## 輸出

回報申請者、申請編號、撤銷結果、網站狀態、操作時間及本機保存結果。僅在網站確認成功時稱為已撤銷。
