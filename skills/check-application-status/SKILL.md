# 查詢申請進度

## 執行前提

需要目前對話可用的 ChatGPT Chrome 操作能力。本機紀錄供尋找申請編號；Google Calendar 不是查詢必要工具。

本專案仍為骨架；網站程序與本機儲存腳本尚未完成驗證，執行前先確認實際可用能力。

## 流程

1. 確認申請者、目標網站及查詢條件。依根目錄 `README.md` 的位置與契約讀取本機紀錄，取得可能的申請編號。
2. 沒有紀錄、讀取能力未完成或資料不足時，使用使用者提供的編號或網站支援的搜尋條件繼續。多筆候選無法唯一辨識時列出差異並請使用者指定。
3. 使用 Chrome 查詢並開啟申請詳情，核對申請者及申請編號，讀取網站實際顯示的狀態與說明。
4. 追加 `action: query` 的操作紀錄，保留舊紀錄。操作成功但保存失敗時，分別回報兩者結果。

## 輸出

回報申請者、申請編號、網站原始狀態、查詢時間與本機保存結果。查詢不到或網站無法連線時明確說明，不以本機歷史狀態冒充即時結果。
