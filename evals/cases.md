# 待執行的流程驗證案例

本表為驗收規劃，尚未代表測試已通過。實際測試記錄應附日期、宿主、plugin 版本與結果；正式提交或撤銷依使用者授權執行。

| 案例 | 預期行為 |
| --- | --- |
| Chrome 工具不可用 | 說明缺少必要能力，不宣稱完成申報 |
| 未連接 Calendar | 可使用手動提供資料提交 |
| 提交資料不足 | 指出缺漏，不自行編造 |
| 提交成功 | 保存實際編號、狀態、申請者及帶時區的時間 |
| 提交後逾時 | 記錄結果未明，先查證再決定是否重送 |
| 本機無申請紀錄 | 使用已提供編號或網站查詢條件，不判定申請不存在 |
| 同條件多筆申請 | 請使用者指定目標，不任意選取或批次撤銷 |
| 查詢狀態改變 | 追加新紀錄，保留舊狀態 |
| 網站不允許撤銷 | 回報原因，不宣稱已撤銷 |
| 撤銷成功 | 再查詢確認網站結果，追加紀錄 |
| 網站操作成功但存檔失敗 | 分開回報，不重複執行網站寫入 |
| Windows 與 macOS 儲存 | 路徑正確解析、權限適當，資料不進入專案或 plugin 目錄 |
| 兩個工作同時追加紀錄 | 各筆 JSONL 完整保留，不交錯或遺失 |
